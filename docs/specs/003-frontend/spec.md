# 003 - Frontend innovador (estilo Jarvis)

## Objetivo

Crear el frontend web de Puente con un diseño distintivo e innovador (estilo Jarvis personal), que sea la interfaz visual del agente para el cliente. Debe marcar la diferencia en diseño y ser memorable.

## Historias

- Como usuario, quiero ver una interfaz oscura y personal (estilo Jarvis) con el agente como único interlocutor.
- Como usuario, quiero un panel de expediente con mis documentos y su estado.
- Como usuario, quiero notificaciones proactivas visibles.
- Como usuario, quiero poder hablar (voz) y escribir (chat) con el agente.
- Como usuario, quiero animaciones sutiles que muestren qué cambió.

## Criterios de aceptación

- [ ] Frontend levanta con `npm run dev` en puerto 5173.
- [ ] Build de producción pasa (`npm run build`).
- [ ] La UI muestra chat, expediente y notificaciones.
- [ ] El diseño es distintivo (no genérico): paleta, tipografía y layout específicos.
- [ ] Responsive (mobile + desktop).
- [ ] Accesible (focus visible, reduced motion).

## Fuera de alcance

- Integración real con el backend (stubs por ahora, V2).
- App móvil nativa (V3).
- Temas personalizables (V2).
