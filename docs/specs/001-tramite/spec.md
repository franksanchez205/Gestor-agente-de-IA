# 001 - Trámite migratorio (MVP)

## Objetivo

Poder gestionar un trámite migratorio completo (renovación de permiso de residencia o apostilla de título) en un solo país, hablando solo con el agente.

## Historias

- Como usuario, quiero decirle al agente qué trámite necesito y que él lo gestione por mí.
- Como usuario, quiero que el agente me pida confirmación antes de enviar documentos o pagar.
- Como usuario, quiero que mis documentos queden guardados en un expediente digital.
- Como usuario, quiero recibir avisos antes de que venza un documento.

## Criterios de aceptación

- [ ] El cliente completa el trámite hablando solo con el agente (WhatsApp o voz).
- [ ] El agente confirma antes de enviar/pagar.
- [ ] El expediente se actualiza con credenciales verificables.
- [ ] El cliente recibe notificaciones proactivas (ej. 60 días antes de vencimiento).
- [ ] Hay pruebas unitarias para memoria, orquestador y razonamiento, y todas pasan.

## Fuera de alcance

- Multi-país simultáneo.
- Multi-trámite simultáneo.
- Marketplace de gestores maduro.
- Asesoría jurídica vinculante.
