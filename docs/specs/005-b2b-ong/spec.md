# 005 - B2B: ONG y organismos de cooperación

## Objetivo

Permitir que ONG y organismos de cooperación que atienden población migrante compren cupos de Puente para su población beneficiaria, con panel de administración y reportes.

## Historias

- Como ONG, quiero comprar cupos de Puente para mis beneficiarios migrantes.
- Como ONG, quiero asignar cupos a beneficiarios específicos.
- Como ONG, quiero ver reportes de uso (trámites gestionados, documentos procesados).
- Como beneficiario, quiero usar Puente con el cupo asignado por la ONG.

## Criterios de aceptación

- [ ] Una ONG puede registrarse y comprar cupos.
- [ ] La ONG puede asignar cupos a beneficiarios (por email/ID).
- [ ] El beneficiario puede usar Puente con el cupo asignado.
- [ ] La ONG ve un panel con reportes de uso.
- [ ] Hay pruebas unitarias para la gestión de cupos y asignación.
- [ ] Cobertura de tests ≥ 80% en los módulos nuevos.

## Fuera de alcance

- Facturación electrónica (V2).
- Multi-ONG (V2).
- SSO para ONG (V2).
